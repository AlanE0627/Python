# 작업 로그 / 진행 현황

## 확정 사항

- 방식: OpenMapleClient + MapleServerAndroid 단일 APK 통합
- UI: v83 원본 UI로 직행 (v209 UI 미사용)
- 입력: 전투·이동 = 게임패드(GameSir X2 Pro, 가상 키 → 키설정표), 창 조작 = 터치
- 범위: 전 직업 스킬 + 퀘스트 + 편의 기능 전부
- 배율: 경험치 10 / 일반 드롭 5 / 보스 드롭 10 / 메소 12(체감 약 30) / 주문서 성공 판정 2회
- 자동줍기: 몹·리액터 드롭 0.45 s 후 원래 줍기 경로로 인벤토리 직행, 원래 빨려 들어가는 애니메이션 유지

## 분석 결과 요약

- 서버 송신 opcode 247종 중 클라이언트 처리 65종, 미처리 182종 (미처리 패킷 = 경고 후 무시, 크래시 없음)
- 싱글플레이 핵심 누락
  - 퀘스트: QUEST_ACTION 송신 코드 없음, QUEST_CLEAR / UPDATE_QUEST_INFO 미처리
  - 스킬: SkillId 98개 정의, 개별 처리 3개, 소환수 클래스 없음 (소환·도어·미스트·콤보 미구현)
  - 맵: 배 운항(CONTI_*), 시계(CLOCK), UI 잠금, NPC_ACTION
  - 편의: 창고(패킷+UI), 상점 결과, 펫 이동·명령·자동 물약, 탈것, 의자, 마스터리북, 몬스터북
- 에셋: 캐릭터·맵·몹·스킬·사운드·스트링 경로 v83 100% 존재, UI 경로 53개 중 38개 v83에 없음 (UIWindow2/4/6, StatusBar3 등 v209 구조)
- Map001(v209)은 로그인·캐릭터 생성 배경 5곳만 사용 → v83 Map.nx Back/login.img로 대체 가능
- 입력: GLFM이 D-pad만 화살표 키로 전달, ABXY·숄더·트리거·스틱 미전달 → 입력 통로 추가 필요
